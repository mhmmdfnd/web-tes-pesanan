Pengaturan

Konfigurasi deployment Vercel.

Environment Variables

API key tidak ditampilkan dan tidak disimpan di browser. Atur di Vercel → Project → Settings → Environment Variables.

FFZ_API_KEY = API key FFZ Store Anda
APP_URL = https://domain-vercel-anda.vercel.app

Catatan keamanan

Dokumentasi FFZ mewajibkan X-API-Key dan IP allowlist. Karena Vercel menggunakan serverless runtime, IP keluar dapat berubah; whitelist IP harus mengikuti ketentuan FFZ Store. Jangan pernah menaruh API key langsung di index.html.
